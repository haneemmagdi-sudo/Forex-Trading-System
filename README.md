# Forex Trading System

نظام تداول فوركس آلي على **MetaTrader 5** بلغة Python، مع طبقة وكلاء للقياس
والتحليل، وواجهة تحكم على الويب.

> **ابدأ من [ARCHITECTURE.md](ARCHITECTURE.md)** لخريطة النظام الكاملة،
> و[AGENTS.md](AGENTS.md) للدليل التشغيلي السريع.

## نظرة سريعة

| المكوّن | التقنية | الدور |
|---|---|---|
| المحرك الحي | Python + FastAPI + MetaTrader5 | إشارة → مخاطر → تنفيذ → مراقبة |
| قرار الدخول | تصويت مرجّح لـ9 مؤشرات + نظام سوقي (FSM) | اتجاه + ثقة |
| التعلّم | scikit-learn (GradientBoosting) + تعديل أوزان حيّ | تحسين من الصفقات المغلقة |
| مجلس الوكلاء | لوحة + إجماع + HMM + تدفق + مناظرة | **وضع الظل: يقيس ولا ينفّذ** |
| فريق المحللين | تقارير → مقترح → قرار → حكم مخاطر | دورة مجدولة كل 60 دقيقة (قياس) |
| الواجهة | Vite + React | `http://localhost:5173` |
| الـ API | FastAPI | `http://localhost:8000/docs` |

## التشغيل

```bat
Start_System.bat          :: الـ backend + الواجهة
Run_Quantum_Trading.bat   :: نفس الشيء + فحص أوزان TimesFM
```

يتطلب: Python 3.11 (`%LOCALAPPDATA%\Programs\Python\Python311`) + Node.js + MT5.
انسخ `.env.example` إلى `.env` واملأ مفاتيحك — **`.env` غير متتبَّع في git**.

## الحالة الصادقة

- الحساب المتصل **ديمو** (`ICMarketsSC-Demo`) مع `LIVE_TRADING_ENABLED=true`.
- الأداء المقيس على 365 صفقة بعائد مسجَّل: نسبة فوز **73.4%**، Profit Factor **1.90**،
  صافي **+310$**، أقصى تراجع **-126$**، ودلالة إحصائية **ضعيفة** (t=2.69).
- نموذج ML دقته 54-56% و**ليس في مسار القرار**.
- الفيتوات المؤسسية **معطّلة افتراضياً** لأن القياس أثبت أنها كانت ترفض 94-96% من
  الصفقات وتُزيل 94% من الربح — التفاصيل في `ARCHITECTURE.md` القسم 8.
- لا يوجد مزوّد LLM عامل حالياً ⇒ المخطط يُرجع `None` (سلوك صحيح ومُعلَن).

**لا تثق بأي رقم في هذا المستودع لم يُنتجه أحد ملفات `*_calibration.py` أو
`council_backfill.py` أو قاعدة البيانات.**
