# 🤖 Quantum Forex AI — دليل تثبيت وتشغيل MT5 Agent

## المتطلبات الأساسية

| المتطلب | الإصدار الأدنى |
|---------|---------------|
| Windows | 10 / 11 |
| Python | 3.10+ |
| MetaTrader 5 | أي إصدار حديث |
| حساب تداول | Demo أو Live |

---

## 📋 خطوات التثبيت (مرة واحدة فقط)

### الخطوة 1: إعداد الموقع

1. افتح الموقع: `https://your-platform.vercel.app`
2. سجّل حساباً جديداً أو ادخل لحسابك
3. اذهب لصفحة **"ربط حساب MT5"**
4. أدخل بيانات حسابك: رقم الحساب، كلمة المرور، اسم السيرفر
5. انسخ **رمز التوكن** (Agent Token) الذي سيظهر لك

### الخطوة 2: تحميل الـ Agent

تأكد من وجود مجلد `mt5-agent` على جهازك

### الخطوة 3: تعديل ملف الإعدادات

افتح ملف `.env` في مجلد `mt5-agent` وعدّل القيم التالية:

```env
# رمز التوكن من صفحة ربط MT5
AGENT_TOKEN=xxxxxxxxxx_توكنك_هنا

# رابط الموقع (بعد النشر)
CLOUD_URL=https://your-platform.vercel.app

# بيانات MT5 (نفس ما في المنصة)
MT5_LOGIN=52763636
MT5_PASSWORD=كلمة_مرورك
MT5_SERVER=ICMarketsSC-Demo
```

### الخطوة 4: التثبيت التلقائي

```
انقر مرتين على: setup.bat
```

هذا الملف سيقوم تلقائياً بـ:
- تثبيت Python إذا لم يكن موجوداً
- تثبيت جميع المكتبات المطلوبة

### الخطوة 5: تشغيل الـ Agent

```
انقر مرتين على: start_agent.bat
```

## 📊 مراقبة الأداء

بعد تشغيل الـ Agent:
1. افتح الموقع → لوحة التحكم
2. ستلاحظ **نقطة خضراء** تشير إلى أن الـ Agent متصل
3. سترى البيانات تتحدث كل 15 ثانية

---

## 🤖 الوكلاء الأربعة

| الوكيل | الوظيفة | التكرار |
|--------|---------|---------|
| **Market Analyst** | تحليل السوق بـ 9 مؤشرات + FSM | كل 5 ثوانٍ |
| **Execution Agent** | فتح الصفقات عند الإشارة القوية | فوري |
| **Monitor Agent** | Break-even / Trailing / Partial | كل ثانية |
| **Learning Agent** | تحسين أوزان المؤشرات من التاريخ | كل 60 دقيقة |

### كيف يتواصل الوكلاء؟

```
Market Analyst
    ↓ إشارة قوية (Signal Bus)
Execution Agent → يفتح الصفقة
    ↓ تأكيد الفتح (Signal Bus)
Monitor Agent  → يراقب SL/TP/Partial
    ↓ الإغلاق (Signal Bus)
Learning Agent → يتعلم من النتيجة
    ↓ تعديل الأوزان
Market Analyst ← أوزان محسّنة
```

## ⚠️ الأسئلة الشائعة

### "MT5 غير متصل — وضع المحاكاة"
هذا طبيعي إذا لم يكن MetaTrader 5 مثبتاً أو مفتوحاً. الـ Agent يعمل بمحاكاة لأغراض الاختبار.

### "agent_token غير صالح"
تأكد من نسخ التوكن بشكل صحيح من صفحة "ربط MT5" في الموقع.

### الـ Agent يتوقف تلقائياً
تحقق من ملف السجل في مجلد `logs/` لمعرفة سبب الإيقاف.

---

## 📞 الدعم

للمشاكل التقنية، أرسل السجل (ملف `.log` من مجلد `logs/`) مع وصف المشكلة.
